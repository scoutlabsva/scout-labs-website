# Scout Labs

Scout Labs helps small businesses adopt AI and automation.

## Principles

- Build simple, maintainable solutions.
- Explain major architectural decisions.
- Prefer Python for automation.
- Prefer TypeScript for web apps.
- Avoid unnecessary complexity.
- Document everything clearly.
- Always suggest opportunities to simplify workflows.
- Ask questions before making assumptions about client requirements.
- Keep code production-ready.

## Scout Labs visual system

Use `/scout-labs-website/design-reference/scout-labs-typography-board.png` as a visual reference,
not as a production asset.

### Typography

- Primary working typeface: Inter.
- Technical accent: IBM Plex Mono, used sparingly.
- Söhne is the preferred premium display typeface, but it may only be used if
  properly licensed font files are present.
- Major headings use sentence case, medium weight, tight tracking, and compact
  line height.
- Body copy uses regular weight, generous line height, and constrained measure.
- Uppercase is reserved for the SCOUT LABS wordmark, eyebrows, tags, and small
  functional labels.
- Buttons use sentence case and medium weight.
- Avoid futuristic, sci-fi, outlined, glowing, or excessively animated text.

### Wordmark

- Display as `SCOUT LABS`.
- Use medium weight and moderately expanded tracking.
- `SCOUT` uses the primary foreground color.
- `LABS` may use the approved Scout green.
- Do not recreate the logo from a raster screenshot. Use an approved SVG.

### Brand tone

The interface should feel precise, intelligent, calm, premium, and technically
credible. It should not resemble an outdoor recreation company or a generic AI
startup.
